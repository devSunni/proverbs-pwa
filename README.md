# 읽으면서 바로 써먹는 어린이 속담 학습 PWA (100개 완비)

**바로 실행하기 (PWA):** https://devsunni.github.io/proverbs-pwa/

찹이 패밀리와 함께 배우는 초등 필수 속담 **100개** 오프라인 설치형 학습 PWA입니다. 스마트폰, 갤럭시 Z 폴드(커버·펼침), 태블릿(세로·가로) 화면에 모두 최적화되어 있습니다.

## 주요 기능
- **초등 필수 속담 100개 완비**: 자음별 분류 (`ㄱ` 18 · `ㄴ·ㄷ` 19 · `ㅁ·ㅂ` 24 · `ㅅ·ㅇ` 22 · `ㅈ~ㅎ` 17), 뜻·이야기·예문·핵심 빈칸 데이터 수록
- **속담 도감 & 3단계 학습 카드**: 실시간 검색·자음·학습상태 필터, 먼저 뜻 생각하기 → 찹이 패밀리 실생활 이야기 → 바로 써먹는 한마디 → 미니 따라쓰기
- **속담 실력 테스트 (퀴즈)**: 뜻 맞추기 · 빈칸 채우기 · 상황극 퀴즈(전체/자음별/오답노트 범위 선택, 연속 콤보, 오답 자동 누적)
- **오늘의 속담 따라쓰기 미션**: 매일 추천되는 3개 속담을 소리 내어 듣고 정확하게 따라 쓰며 스탬프 획득
- **내 학습장 & 배지**: 자음별 정복률, 배지 4종, 오답노트 집중 복습, 학습 기록 JSON 내보내기
- **이중 한국어 TTS 엔진**: Web Speech API 한국어 음성 자동 선택·충돌 방지 + 미지원/차단 환경 자동 오디오 TTS 폴백
- **듀얼 프로필 & 상태 자동 복원**: 준우/지우 개별 학습 기록(외운 속담·즐겨찾기·오답·따라쓰기·배지)과 마지막 탭·필터·퀴즈 설정을 `localStorage`에 자동 저장
- **네이티브 앱 터치 경험**: 롱프레스 팝업·텍스트 선택 차단, 오프라인 캐싱(`sw.js`), 설치 프롬프트 지원

## 기기에 설치 방법
1. 위 주소(https://devsunni.github.io/proverbs-pwa/)로 접속합니다.
2. **Android Chrome / 삼성 인터넷**: 상단 `📲 앱 설치` 버튼 또는 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
3. **iPhone / iPad Safari**: 공유 버튼 → **홈 화면에 추가**
4. **PC Chrome / Edge**: 주소창 오른쪽 **설치** 아이콘 클릭

## 포함된 파일
- `index.html`: 메인 앱 (100개 속담 데이터, 도감·퀴즈·따라쓰기·내 학습장, 이중 TTS 엔진, 반응형 레이아웃)
- `manifest.json`: PWA 설치 매니페스트 (`orientation: "any"`, `any` / `maskable` 아이콘 분리)
- `sw.js`: 오프라인 캐싱 서비스 워커 (stale-while-revalidate + 오프라인 네비게이션 폴백)
- `icon-192.png`, `icon-512.png`: 앱 아이콘
- `assets/`: `chabi-mascot.jpg`, `chabi-hero.jpg` 마스코트 및 배너 이미지
- `tests/`: Node.js 데이터·로직·PWA 무결성 테스트 (`node --test tests/*.test.js`)
